# Santa Rita Pizza

Landing page e cardápio digital para uma pizzaria fictícia, desenvolvido com foco em apresentação visual, navegação simples e experiência responsiva.

## Objetivo

Criar uma página web para apresentar a pizzaria, destacar produtos e facilitar o acesso ao cardápio digital.

## Funcionalidades

- Página inicial com apresentação da pizzaria
- Cardápio digital
- Organização visual dos produtos
- Estrutura responsiva
- Navegação entre páginas
- Deploy online

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel

## Deploy

Projeto disponível online pelo link configurado no repositório.

## Aprendizados

Durante o desenvolvimento, pratiquei estruturação de páginas HTML, organização de arquivos CSS e JavaScript, responsividade e publicação de projeto front-end em ambiente online.

## Melhorias futuras

- Melhorar responsividade em diferentes tamanhos de tela
- Adicionar filtros por categoria no cardápio
- Melhorar acessibilidade dos botões e textos
- Adicionar imagens otimizadas
- Criar uma seção de contato com chamada para WhatsApp
